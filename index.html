시험 응시 방법
온
온라인 시험 LMS(강의실) → 온라인 시험 → "응시" 클릭
과
과제형 시험 LMS(강의실) → 과제 → 조회 → "제출" 클릭
💻 권장 브라우저: Microsoft Edge 또는 Chrome
✕ Internet Explorer는 사용하지 마세요
✅
응시 전 필수 확인사항
각 강의실 교수님 공지에서 시험유형·시험시간 확인
시험점검 테스트 반드시 실시 (오디오파일 작동·PC 상태 점검)
준비물: PC (핸드폰 불가) + 공동인증서 또는 네이버인증서 + 1인 1인터넷 조용한 장소
사전 점검 없이 시험 중 오류 발생 시 구제 불가
장애학생: 입학 시 장애인증명서 제출자 → 시험시간 2배 제공 (과제·토론 제외)
🚫
시험 중 절대 금지사항
✕
화면 이탈 또는 다른 프로그램 사용 시험 화면이 아닌 곳 클릭 / 검색 이동 = 화면이탈
✕
동일 장소 2명이 하나의 IP 동시 사용 동일 IP 사용 시 3시간 간격을 두고 응시
✕
특수키 사용 (Alt, Ctrl, Windows key 등) 복사·붙여넣기·검색 등 불가
✕
내 아이디로 두 컴퓨터에 동시 접속 중복 로그인 = 부정행위
⚠️
주요 유의사항
🔐
인증서 로그인 의무 공동인증서 또는 네이버인증서 중 하나로 로그인 필수. 모바일 응시 불가, PC로만 가능.
☝️
온라인 시험은 1회로 완료 한 번 '응시' 클릭 후 재접속 불가. 시험 시간 경과 시 자동 제출됨.
⏰
마지막 날 응시 주의 동시 접속자 폭증으로 인터넷이 느려질 수 있습니다. 시험 일정 기간 중 미리 응시하세요!
💻
노트북 터치패드 주의 노트북으로 응시할 경우 터치패드로 화면이탈 발생 가능. 터치패드를 끄고 응시하세요.
