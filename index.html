응시 전 필수 확인사항
각 강의실 교수님 공지에서 시험유형·시험시간 확인
시험점검 테스트 반드시 실시 — 오디오 작동·PC 상태 점검
준비물: PC (핸드폰 불가) · 공동/네이버 인증서 · 1인 1인터넷 장소
사전 점검 없이 시험 중 오류 발생 시 구제 불가
장애학생: 장애인증명서 제출자 → 시험시간 2배 제공 (과제·토론 제외)
🚫
시험 중 절대 금지사항
✕
화면 이탈 또는 다른 프로그램 사용 시험 화면 외 클릭·검색 이동 = 화면이탈
✕
동일 장소 2명이 하나의 IP 동시 사용 동일 IP 사용 시 3시간 간격을 두고 응시
동일한 IP사용자 2명 이상이 "시험응시"를 클릭하면, 2번째 이후 접속자부터 팝업이 뜹니다. 팝업창 각 문항에 [중복사유]를 체크하고 유의사항을 숙지한 후 동의체크 → [시험응시 시작] 버튼을 클릭하면 응시 시작됩니다.
✕
특수키 사용 (Alt, Ctrl, Windows key 등) 복사·붙여넣기·검색 등 불가
✕
내 아이디로 두 컴퓨터에 동시 접속 중복 로그인 = 부정행위
⚠️
주요 유의사항
🔐
인증서 로그인 의무 공동인증서 또는 네이버인증서 필수. 모바일 응시 불가, PC로만 가능.
☝️
온라인 시험은 1회로 완료 응시 완료 후 '제출' 클릭 후 재접속 불가. 시험시간 경과 시 자동 제출됨.
⏰
마지막 날 응시 주의 동시 접속자 폭증으로 인터넷이 느려질 수 있습니다. 미리 응시하세요!
💻
노트북 터치패드 주의 터치패드로 화면이탈 발생 가능. 응시 전 터치패드를 끄세요.
